# assets/sprites/backgrounds

스토리 재생 화면의 **배경 아트**. 챕터 기본 배경(`StoryChapterData.background`)과 줄 단위 장면 전환(`StoryLineData.background`)에 쓴다.

| 파일 | 장면 |
|---|---|
| `city_night.png` | 현대 도시 거리 (챕터 1 도입 — 고백) |
| `forest.png` | 숲길 (챕터 1 등산) |
| `village.png` | 원시 부락 (챕터 3 도입) |
| `village_burning.png` | 불타는 부락 (챕터 2) |
| `highland.png` | 고원에서 내려다본 평야 (챕터 3 이동) |
| `riverside.png` | 물가 (챕터 3 도착) |
| `snow_valley.png` | 눈 덮인 협곡 (챕터 1 여신 장면) — 대본은 "온통 하얀 공간"이라 **전용 배경이 들어올 때까지의 대역**이다 |

## 규격

- **가로 960 안팎**(현재 960x657). 화면 뷰포트는 1280x720 이라 이보다 작지만, 배경은 대사 상자와 인물 뒤에 깔리는 그림이라 약간 확대되어도 문제되지 않는다. 용량 쪽을 택한 결과다(#272 — 원래 1216x832, 장당 1.9MB였다).
- **되도록 16:9 로 그린다.** 화면은 `KEEP_ASPECT_COVERED` 로 채우므로 비율이 달라도 되지만, 지금처럼 세로로 긴 그림(1.46:1)은 **세로 약 18%가 잘려 나간다** — 저장하고 VRAM 에 올려도 화면에 안 나오는 픽셀이다. 세로로 긴 그림은 좌우가 크게 잘린다.
- **불투명 PNG**. 배경이므로 알파가 필요 없다.
- **아래쪽 1/3 은 인물과 대사 상자가 덮는다.** 중요한 것을 그 자리에 두지 않는다.
- 인물이 그 앞에 서므로 **사람은 그리지 않는다.**

## 흐림 (Blur)

화면이 배경에 **살짝 흐림**을 건다(`screens/story/background_blur.gdshader`). 배경이 선명하면 그 앞에 선 인물·대사 상자와 같은 층으로 읽혀 화면이 시끄럽다.

**그림 파일은 선명한 원본 그대로 둔다.** 미리 흐리게 구우면 되돌릴 수 없고 세기를 바꿀 때마다 에셋을 다시 만들어야 한다. 세기는 셰이더의 `blur_radius`(텍셀) 하나로 조절한다.

## 새 배경을 넣는 법

1. 파일을 이 폴더에 둔다.
2. 챕터 기본 배경이면 `data/story/chapter_*.tres` 의 `background` 에, 도중 전환이면 그 줄(`StoryLineData`)의 `background` 에 건다.
3. 코드는 고치지 않는다. 배경이 없으면 화면이 챕터 번호로 만든 그라데이션으로 떨어진다.
