## ONE 모바일 POP체 받기

이 글꼴은 **저장소에 커밋하지 않는다.** 라이선스가 상업적 이용과 앱·프로그램 임베딩은
허용하지만 **글꼴 파일 자체의 재배포·수정·판매는 금지**하고, 이 저장소는 공개라서 파일을
올리면 그 자체가 재배포가 된다. 그래서 `.gitignore` 에 넣어 두었다.

1. 원스토어 공식 배포처에서 받는다: <https://www.onestorecorp.com/sv/fordev_font/>
2. 압축을 풀고 **`ONE Mobile POP OTF.otf`** 를 이 폴더에 **`ONE-Mobile-POP.otf`** 라는 이름으로 넣는다.
   (TTF 판도 같은 글꼴이지만 4MB 로 OTF 의 3배라 OTF 를 쓴다.)
3. `godot --headless --path . --import` 를 한 번 돌리거나 에디터를 다시 연다.
   `.import` 가 생기기 전에는 `ResourceLoader.exists()` 가 `false` 라 글꼴이 적용되지 않는다.

**파일이 없어도 게임은 돈다.** 기본 글꼴은 엔진 기본 글꼴로, 전투 한글은 도현으로 떨어진다.
화면이 예전 글꼴로 보이면 이 파일이 빠진 것이다.

### 라이선스 요지 (㈜원스토어)

- 개인·기업 모두 무료, 모든 용도의 상업적 이용 가능
- 웹사이트·프로그램·전자책 임베딩 가능
- 글꼴 파일 자체의 유료 판매·수정·재배포 금지
- 지적재산권은 ㈜원스토어에 있다

약관은 바뀔 수 있으므로 배포 전에 위 공식 페이지에서 최신 내용을 확인한다.
