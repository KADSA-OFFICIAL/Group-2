# data/portraits

초상 아트의 **얼굴 위치·크기**를 저작하는 곳이다. 그림 파일은 `assets/sprites/characters/portraits/` 에 있고, 여기에는 그 그림을 어떻게 잘라 보여 줄지 정하는 값만 둔다.

## 왜 필요한가

`tools/normalize_portrait.gd`(#198)가 캔버스 비율과 인물 세로 점유율을 통일해서, **전신**으로 보여 주는 자리(캐릭터 상세·장비)는 이미 크기가 같다.

문제는 **얼굴을 크게 보여 주는 자리**다. 파티 슬롯·목록 썸네일은 머리 크기에 맞춰 잘라야 하는데, 인물 경계상자로는 그걸 알 수 없다 — 팔을 벌린 포즈는 경계상자가 넓고 붙인 포즈는 좁아서, 경계상자에서 도출한 크롭은 같은 슬롯에서 얼굴 크기가 2배 넘게 차이 났다.

## 값 읽는 법

`head_rects` 는 `portrait_id -> Rect2` 이고, **캔버스 대비 비율(0~1)**이다.

- `position` : 머리카락 꼭대기 왼쪽 모서리
- `size.y`   : 머리카락 꼭대기 ~ 턱
- `size.x`   : 얼굴 폭(머리카락 제외)

새 초상을 추가하면 여기 한 줄을 더한다. 저작하지 않으면 자동 추정으로 떨어지므로 화면이 깨지지는 않지만, 그 인물만 얼굴 크기가 어긋난다.

## 재는 법

그림 위에 10% 격자를 얹어 눈으로 읽는 편이 정확했다. 자동 검출(경계상자 폭 / 살색 / 어두운 눈 픽셀)은 머리카락·트윈테일·검은 옷 때문에 그림마다 다른 곳을 짚었다.
