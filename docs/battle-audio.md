# 전투 오디오 (#516)

전투곡은 64초/120BPM, 44.1kHz OGG Vorbis이며 반복 재생한다. MusicSystem의 기존 전환 페이드는 유지하고, 곡 내부에는 전체 페이드가 없다. 로비 오버레이가 열리면 로비 곡, 닫히면 전투 곡이 재생된다. 로비 런처의 정지 요청 뒤 전투가 음악을 요청하도록 지연 신호 연결을 사용한다.

타격·자물쇠·격파 파열·상태 배지·사망 연출에 각각 SE를 연결했다. 기존 await/연출 시간은 바꾸지 않았다. lock은 PresentationQueue의 pitch를 그대로 사용한다. 동시 음성은 8개, 각 -15dB로 제한한다. 누락된 파일은 재생을 건너뛴다.

heal.ogg는 회복 숫자/이펙트 이벤트 경로가 아직 없으므로 fx_heal과 함께 보관한다. 이번 변경에서 회복 전투 규칙이나 새 이벤트를 만들지 않았다.

음원은 직접 작곡한 합성 악기 기반이다. 헤드리스 검수는 디코딩, 루프 설정, 로비/전투 전환, 누락 폴백, 음정 전달, 음성 수 제한을 확인한다. 실제 청취 및 기기별 음량 밸런스 검수는 별도로 필요하다.
