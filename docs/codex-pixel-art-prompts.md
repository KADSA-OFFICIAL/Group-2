# Codex 픽셀 아트 프롬프트 — 아린 · 익룡 여왕 (#380)

Codex 에 **그대로 붙여 넣는** 프롬프트 모음. 각 프롬프트는 **자기 완결적**이다 —
Codex 는 이 저장소를 읽지 않으므로 필요한 규약·수치를 프롬프트 안에 전부 적었다.

스펙의 정본은 따로 있다. 값이 바뀌면 **프롬프트가 아니라 아래를 본다.**

## 쓰기 전에 — 세 가지

1. **`tint` 결정이 먼저다.** 두 캐릭터 모두 `tint` 가 다른 색과 충돌해 변경이 제안된 상태다
   (아린 문서 §9-1, 여왕 문서 §5-1). 이펙트 색이 전부 `tint` 에서 나오므로 흔들리면 다시 그린다.
   아래 프롬프트는 **제안된 값**(아린 `D9B26A`, 여왕 `8B6BB0`)을 박아 넣었다 — 결정이 달라지면
   프롬프트의 그 줄만 고친다.
2. **재생 코드가 없는 애니메이션은 요구하지 않았다.** Idle·피격·공격·사망·비행은 이 게임에
   재생 경로가 없다. 프롬프트에 넣으면 창고에 쌓인다.
3. **산출물은 정규화 도구를 거치지 않는다.** `tools/normalize_walk_sheet.gd` 는 생성기 산출물의
   흘러가는 여백을 잡는 도구다. 격자에 맞춰 찍은 도트에 쓰면 오히려 재배치로 픽셀이 밀린다.

## 프롬프트 1 — 아린 워크 시트

```
2D 픽셀 아트 워크 사이클 스프라이트 시트를 만들어 줘. 게임에 바로 넣을 에셋이라
격자 규격을 정확히 지켜야 해.

[출력]
- PNG 1장, 정확히 144 x 192 px, 투명 배경(RGBA)
- 3열 x 4행 = 12칸. 각 칸은 정확히 48 x 48 px
- 업스케일하지 마. 네이티브 48x48 그대로 내보내.
- 안티에일리어싱 금지. 모든 픽셀은 팔레트의 색 중 하나여야 해(중간색 생성 금지).

[격자 의미]
- 행 0 = 정면(아래를 보고 걷기)
- 행 1 = 왼쪽을 보고 걷기
- 행 2 = 뒷모습(위를 보고 걷기)
- 행 3 = 오른쪽을 보고 걷기
- 각 행의 열 0,1,2 = 워크 사이클 3프레임. 0 -> 1 -> 2 -> 0 으로 8fps 반복 재생돼.
- **열 0 은 정지 포즈다.** 캐릭터가 멈추면 이 프레임에서 정지하므로, 서 있는 자세로
  단독 성립해야 해. 양발을 붙이고 무게 중심을 가운데 둬.
- 열 1 = 왼발 앞 + 몸통 1px 아래로. 열 2 = 오른발 앞 + 몸통 1px 아래로.
  열 2 를 열 1 의 좌우 반전으로 만들지 마. 다시 그려.
- 행 3 을 행 1 의 좌우 반전으로 만들지 마. 비대칭 트윈테일이 반대쪽으로 넘어가서
  다른 인물처럼 보여.

[셀 안 배치 — 어긋나면 캐릭터가 공중에 뜬다]
- 캐릭터 키는 36 px. 셀 48 안에서 발바닥이 y = 44 에 닿아야 해(아래 여백 3px).
- 머리 위로 남는 8px(y 0~7)은 트윈테일 들림과 고글 자리야.
- 가로는 셀 중앙 정렬.
- 모든 파츠를 정수 픽셀 그리드에 정렬해. 서브픽셀·회전 금지.

[캐릭터 — 아린]
겸직(원거리 딜러 + 탱커) 여성 캐릭터. 전기 창을 든 도발적인 인상.
36px 키에서 이 3가지만으로 다른 캐릭터와 구분돼야 해:
  1. 비대칭 트윈테일 — 한쪽이 길게 흘러내림
  2. 어깨의 각진 아우터 — 목 뒤로 솟은 하이칼라
  3. 머리 위 고글 — 실루엣 상단의 가로선
얼굴은 눈·눈썹·입 세 개만. 코·귀·볼은 그리지 마(공간이 없어).
  - 눈: 세로 3px, 가로 4px, 눈 사이 3px. 홍채 안에 1px 하이라이트(광원 반대편)
  - 눈썹: 1~2px. 안쪽 끝을 1px 내려서 호전적인 인상을 만들어
  - 입: 2~3px, 송곳니는 1px 흰 점 하나
창은 손에 들린 소품이야(던지지 않아). 전체 24px, 파츠 3개로만 압축:
  창날 7px(이엽, 중앙 1px 슬릿 F7F3EA) / 부유 링 2px(자루와 1px 떨어뜨려) / 자루 15px 1px 굵기.
  대각선으로 놓을 땐 45° 고정.
트윈테일 끝단만 2px 진폭으로 흔들되, 몸통보다 1프레임 늦게 따라오게 해.

[팔레트 — 정확히 이 14색만 써. 다른 색을 만들지 마]
머리 하이라이트 #F7F3EA / 머리 메인 #D9B26A / 머리 섀도 #A8823F / 머리 딥섀도 #6E5526
이너 헤어 #6B8FA8 / 이너 헤어 섀도 #4A6879
피부 #DCCDAF / 피부 섀도 #B39A78
의상 다크 #3B342B / 의상 다크 섀도 #2E2A24
의상 앰버 #D9B26A / 의상 앰버 섀도 #A8823F
눈 홍채 #D9B26A / 눈 하이라이트 #F7F3EA
아웃라인 #2E2A24 (1px, 셀렉티브 — 전체를 두르지 말고 실루엣 경계에만)

이 팔레트는 흙 톤 게임에 맞춘 거야. 형광색·채도 높은 원색을 절대 넣지 마.
파트당 3톤 이하. 그라데이션 금지. 디더링은 쓰지 마.
```

## 프롬프트 2 — 아린 이펙트 세트

> **주의**: 아린의 이펙트는 지금 **절차적으로 그려진다**(`StrikeEffect`, `ConeEffect`,
> `OverloadEffect`). 부채꼴은 조준 각도가 연속값이라 사전 렌더로 교체할 수 없다
> (아린 문서 §9-4). 그래서 이 프롬프트는 **절차적 도형을 대체하는 것이 아니라
> 그 위에 얹는 오버레이 도트**를 요구한다.

```
2D 픽셀 아트 이펙트 스프라이트 시트를 만들어 줘. 게임의 전기 속성 스킬 연출이야.

[공통 규격]
- 모두 네이티브 해상도로, 업스케일하지 마. 투명 배경(RGBA).
- 게임에서 3배 확대해 그리므로 1 도트 = 3 월드 px 로 생각하고 크기를 잡아.
- 안티에일리어싱 금지. 아래 팔레트 색만 사용.
- 애니메이션은 전부 12fps 기준이야.

[팔레트 — 이 5색만]
코어 #F7F3EA (가장 밝은 중심)
메인 #D9B26A (전기 본체)
글로우 #A8823F (메인을 어둡게 한 외곽)
디버프 #A78BC8 (감전 표시 전용)
먼지 #9A9691 (넉백 먼지 전용)
형광색 금지. 흙 톤 게임이야.

[전기를 그리는 규칙 — 전부에 적용]
- 볼트는 3톤 고정: 코어 1px #F7F3EA + 양옆 1px #D9B26A = 총 3px 굵기.
- **꺾임은 45° 또는 수직/수평만.** 임의 각도는 계단 현상으로 지저분해져.
  좋음: 세로로 내려오다 45°로 꺾이고 다시 세로. 나쁨: 완만한 대각선.
- 꺾임 3~4회, 각도는 불규칙하게.

[만들 것 — 각각 별도 PNG, 가로로 프레임 나열]

1) 낙뢰 예고 링 — 2프레임, 각 40x40
   착탄 지점 지면에 놓이는 1px 링. 채우기 없음. 색 #D9B26A.
   프레임마다 안쪽으로 1px 수축. 원근을 위해 세로로 눌린 타원(가로:세로 = 2:1).

2) 낙뢰 강하 볼트 — 3프레임, 각 24x80
   위에서 아래 착탄점으로 뻗는 볼트. 위 규칙대로 3px 굵기, 45° 꺾임.
   프레임 2 에서 짧은 가지 2개를 좌우로(각 2도트).
   프레임 3 에서 아래쪽만 남기고 위가 사라지기 시작.

3) 낙뢰 착탄 스파크 — 4프레임, 각 40x40
   중심에서 방사형 6갈래. 길이가 프레임마다 늘었다가 사라짐.
   프레임 1 만 중심에 #F7F3EA 플래시(3x3).
   프레임 4 는 잔류 점 2~3개만.

4) 감전 표시 — 3프레임, 각 32x16
   적 발밑에 놓이는 눌린 타원 링. 색 #A78BC8, 1px.
   **깜빡이지 말 것.** 세 프레임 모두 링이 있고 안쪽 스파크 점 위치만 바뀌어야 해.
   (이 상태는 0.3초로 짧고 연속으로 재적용되는데, 껐다 켜면 발작처럼 보여.)

5) 넉백 먼지 퍼프 — 3프레임, 각 16x8
   지면에서 옆으로 퍼지는 먼지. 색 #9A9691. 알파 대신 점 밀도로 옅어짐을 표현.
   프레임마다 옆으로 퍼지며 위로 1px 뜸.

6) 부채꼴 내부 볼트 결 — 1장, 32x8, 가로 타일링 가능
   좌우 끝이 이어지는 1px 지그재그 선. 색 #D9B26A.
   절차적으로 그려진 부채꼴 위에 겹쳐 깔 거야.

7) 과부하 시전 링 웨이브 — 3프레임, 각 64x32
   눌린 타원 링이 바깥으로 커지며 옅어짐. 색 #D9B26A -> #A8823F.

8) 과부하 부유 스파크 유닛 — 3프레임, 각 8x8
   1px 점 -> 십자 3px -> 1px 점. 색 #F7F3EA.
   캐릭터 주변에 랜덤 위치·랜덤 시작 프레임으로 4~6개 뿌릴 단위야.
   **동시에 켜지면 안 되므로** 단위 하나만 만들면 돼.

9) 과부하 종료 방전 — 3프레임, 각 48x48
   캐릭터를 감싸던 전기가 아래로 흘러 사라짐. 색 #D9B26A -> #A8823F -> 소멸.
```

## 프롬프트 3 — 익룡 여왕 워크 시트

```
2D 픽셀 아트 워크 사이클 스프라이트 시트를 만들어 줘. 게임 보스 캐릭터야.
게임에 바로 넣을 에셋이라 격자 규격을 정확히 지켜야 해.

[출력]
- PNG 1장, 정확히 144 x 192 px, 투명 배경(RGBA)
- 3열 x 4행 = 12칸. 각 칸은 정확히 48 x 48 px
- 업스케일하지 마. 네이티브 48x48 그대로.
- 안티에일리어싱 금지. 팔레트 색 외의 중간색 생성 금지.

[격자 의미]
- 행 0 = 정면(아래) / 행 1 = 왼쪽 / 행 2 = 뒷모습(위) / 행 3 = 오른쪽
- 각 행 열 0,1,2 = 워크 3프레임, 8fps 로 0->1->2 반복.
- **열 0 은 정지 포즈다.** 멈추면 이 프레임에서 정지해.
- 행 3 을 행 1 의 좌우 반전으로 만들지 마 — 지팡이가 반대손으로 넘어가.

[셀 안 배치]
- 캐릭터 키 36 px, 발바닥이 y = 44 에 닿게(아래 여백 3px). 가로는 중앙 정렬.
- 머리 위 8px(y 0~7)은 헤드피스 자리.
- 정수 픽셀 그리드 정렬. 서브픽셀·회전 금지.

[캐릭터 — 익룡 여왕]
우아하고 오만한 마법사 여왕. 은발 장발, 보라 드레스, 금 장식, 긴 지팡이.
36px 에서 이 3가지만으로 다른 적(네발 랩터, 덩치 큰 매머드)과 갈려야 해:
  1. 비대칭 스파이크 헤드피스 — 실루엣 상단 오른쪽으로 솟은 뿔 2~3개
  2. 바닥까지 끌리는 드레스 자락 — **실루엣 하단이 넓게 퍼지는 삼각형**
     (위는 좁고 아래가 퍼진다. 이게 다른 적과 갈리는 가장 큰 특징이야)
  3. 오른손의 긴 지팡이 — 실루엣을 세로로 가르는 직선 + 상단에 초승달 고리
     (이 게임에서 세로 직선을 가진 유일한 유닛이야. 반드시 살려)
얼굴은 눈·눈썹·입만:
  - 눈: 세로 3px, 가로 4px. 홍채 #8B6BB0, 1px 하이라이트 #F7F3EA
  - 눈썹: 1px. **바깥쪽 끝을 1px 올려서** 내려다보는 오만한 인상을 만들어
  - 입: 1~2px 옅은 호. 이는 그리지 마

[워크 3프레임 — 발이 아니라 자락으로 걷는다]
드레스가 발목을 덮어 발이 거의 안 보여. 보행은 자락과 머리카락으로 읽혀야 해.
  열 0 = 정지. 무게 중심 중앙, 지팡이 수직, 자락 정지.
  열 1 = 몸통 1px **위로**(뜬다), 자락 왼쪽 2px, 머리카락 끝 1px 뒤로.
  열 2 = 몸통 1px 위로, 자락 오른쪽 2px, 머리카락 끝 1px 앞으로.
- 몸통을 아래로 누르지 말고 **위로** 띄워. 미끄러지듯 걷는 인상이 나야 해.
- 자락·머리카락은 몸통보다 1프레임 늦게 따라와.
- **지팡이는 흔들지 마.** 세로 직선이 식별 요소인데 흔들면 무너져.

[팔레트 — 정확히 이 16색만]
머리 하이라이트 #F7F3EA / 머리 메인 #D8D3CC / 머리 섀도 #9A9691 / 머리 딥섀도 #6E6558
드레스 메인 #8B6BB0 / 드레스 섀도 #5E4578 / 드레스 딥섀도 #3A2C4A
성운 #A78BC8 (드레스 자락 안쪽에 디더링으로만)
금 장식 #D9B26A / 금 장식 섀도 #A8823F
흑 파츠 #3B342B / 흑 파츠 섀도 #2E2A24
피부 #DCCDAF / 피부 섀도 #B39A78
눈 홍채 #8B6BB0
아웃라인 #2E2A24 (1px 셀렉티브)

형광색·원색 금지. 파트당 3톤 이하. 그라데이션 금지.
디더링은 드레스 자락의 성운 표현에만 쓰고 다른 곳엔 쓰지 마.
```

## 프롬프트 4 — 익룡 여왕 탄 이펙트

```
2D 픽셀 아트 투사체 스프라이트를 만들어 줘. 보스가 쏘는 마법 탄 2종이야.
```

## 산출물이 오면 — 연결 순서

두 캐릭터 모두 같다. **시트를 붙이고 화면에 세워 본 뒤에** 이펙트로 넘어간다 —
키가 어긋난 것을 이펙트를 다 그린 뒤에 발견하면 되돌리는 비용이 크다.

1. PNG 를 각각 `assets/sprites/characters/arin_walk.png` /
   `assets/sprites/enemies/pterosaur_queen_walk.png` 로 넣는다.
   **`normalize_walk_sheet.gd` 를 돌리지 않는다**(위 "쓰기 전에" 3번).
2. `SpriteFrames`(`*_walk_frames.tres`)를 만든다 — 4애니 × 3프레임, 8fps, loop.
   이름은 `walk_down` / `walk_left` / `walk_up` / `walk_right` 고정.
3. `.tres` 에 연결한다.

   | | 아린 | 여왕 |
   |---|---|---|
   | `walk_frames` | `arin_walk_frames.tres` | `pterosaur_queen_walk_frames.tres` |
   | `walk_sprite_scale` | `(3, 3)` | `(4, 4)` |
   | `walk_sprite_offset` | `(0, -15)` | `(0, -15)` |

4. **씬의 `AnimatedSprite2D` 에 `texture_filter = Nearest`** 를 건다.
   전역 설정(`project.godot`)은 건드리지 않는다 — 0.25 로 줄여 쓰는 기존 시트가 거칠어진다.
5. `godot --headless --path . --import` 를 돌리고 `.import` 파일을 함께 커밋한다.
   안 하면 `ResourceLoader.exists()` 가 `false` 라 코드가 파일을 못 찾는다.
6. 전장에 세워 확인한다. 아린은 `stage_1_1`, 여왕은 `stage_test` 4파.
   **발이 땅에 닿는지**와 **화면 키**(아린 108px / 여왕 144px)를 눈으로 본다.
