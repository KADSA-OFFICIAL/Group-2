# 턴제 전투 정지 스프라이트 프롬프트 (#478)

> **#485 재작업 반영 (2026-09-11):** 아군 6명·적 6체를 원본 초상 화풍에 맞춰 다시 생성했다.
> 강지·아린은 공유 초상과 전신·아이콘·컷인까지 통일했다. 피부까지 물들이던 4색 내보내기를 제거했다.
> 매머드 2종·여왕은 사람 얼굴의 여성 수인, 벨로 2종은 자세·꼬리 실루엣으로 구분한다.
> 현행 산출물·프롬프트·검수는 [아트 README](../art/battle-sprites/README.md)를 따른다.
> 아래 §4의 수치는 #480 당시 기록이다. 현행 검사는 피부/초상 회귀 검사를 포함한 **238개**다.

턴제 전투 화면에서 **네모로 서 있는 것들**을 그림으로 바꾸기 위한 프롬프트 모음.

각 프롬프트는 **자기 완결적**이다 — 생성 도구는 이 저장소를 읽지 못하므로 필요한
규약·수치를 프롬프트 안에 전부 적었다. 값이 바뀌면 프롬프트가 아니라 아래 정본을 본다.

| 대상 | 정본 |
|---|---|
| 표시 칸·발 기준선 | `stage/turn/TurnBattle.gd` 의 `ALLY_BODY` / `ENEMY_BODY` |
| 원소 7색 · UI 색 | `entities/combat/turn/TurnCombat.gd` |
| 공통 아트 규율 | 캐릭터 아트 에셋 제작 가이드 §5 |
| 초상·컷인·엠블럼 | [turn-combat-design.md](turn-combat-design.md) §14 "캐릭터 아트 적용" |
| 워크 시트(실시간 화면) | [pixel-art-prompts.md](pixel-art-prompts.md) — **이 문서와 다른 에셋이다** |

## 0. 네모의 정체

턴제 전투 화면은 Phase 0(감각 검증) 단계라 유닛을 `ColorRect` 로 세운다.
`tint` 색 네모 하나가 캐릭터 자리를 대신하고, 그 위에 원소 문양 라벨만 붙는다.

지금은 `battle_sprite` 슬롯이 열려 있다.

```
CharacterData.battle_sprite : Texture2D   # 아군
EnemyData.battle_sprite     : Texture2D   # 적
```

**비어 있으면 네모, 채우면 그림이다.** `.tres` 에 텍스처만 넣으면 되고 스크립트를
고칠 필요가 없다. 아래 프롬프트의 산출물이 곧 이 슬롯에 들어간다.

### 워크 시트를 빌려 쓰지 않는 이유

`assets/sprites/characters/` 에 이미 워크 시트가 있고 그 한 컷을 잘라 쓸 수도 있다.
그러면 오늘 당장 네모가 사라진다. 다만 워크 시트는 **실시간 화면의 4방향 이동용**이라
측면 컷이 "걷다 멈춘 자세"로 굳어 보이고, 셀 안 인물이 프레임마다 흘러가는 문제
(`tools/normalize_walk_sheet.gd` 머리말)를 이 화면에서 다시 겪는다.
급하면 임시로 쓸 수 있지만, 이 문서가 요구하는 것은 **제자리 전투 자세 한 장**이다.

## 2. 공통 규격 — 두 레인 모두 지킨다

### 2-1. 표시 칸과 발 기준선

```
아군 칸  84 × 126 px     적 칸  93 × 117 px      (#492 에서 1.5배로 키웠다)
발밑이 노드 원점이다 (position = -칸 * (0.5, 1))
```

전투 화면은 `STRETCH_KEEP_ASPECT_CENTERED` 로 넣으므로 **늘어나지 않는다.**
대신 비율이 다르면 칸 안에 여백이 생긴다. 아래 캔버스 비율을 맞추면 여백이 없다.

| 대상 | 제작 캔버스 | 배율 | 화면 크기 |
|---|---|---|---|
| 아군 | **224 × 336** | 1/2.67 | 84 × 126 |
| 적 | **248 × 312** | 1/2.67 | 93 × 117 |

**캔버스는 바뀌지 않았다.** 4배로 그려 둔 덕분에 #492 가 표시 칸을 1.5배로 키울 때
아트를 다시 뽑을 필요가 없었다 — 이것이 4배로 그리는 이유다(§2-4).

### 2-2. 등신 — 여기서는 치비다

캐릭터 아트 가이드 §5 는 **7~7.5등신**을 고정으로 못박는다. 그건 전신 일러스트·컷인
기준이고, **이 에셋에는 적용할 수 없다.**

```
표시 높이 84px 에서 7등신 → 머리 12px → 눈·입이 1px 씩 → 얼굴이 사라진다
(#492 로 126px 가 되었지만 7등신이면 여전히 머리 18px 다)
```

이 에셋은 **4등신**으로 그린다(머리 = 전체의 1/4 ≈ 화면 21px). 가이드와 어긋나는
지점이므로 적어 둔다 — 어긋난 게 아니라 **다른 용도**다. 컷인·편성 전신은 계속
7~7.5등신을 지킨다.

### 2-3. 그 외 공통 규율 (가이드 §5 그대로)

| 항목 | 값 |
|---|---|
| 광원 방향 | **좌상단 45° 고정** |
| 그림자 색 | **순수 검정 금지.** 주색의 보색 계열 어두운 톤 |
| 팔레트 상한 | 주요 색군 4개를 기준으로 하되 **피부·눈·원소 장식·음영·선·안티앨리어싱은 별도**. 전경 전체 4색 양자화 금지 (#485) |
| 원소 색 | 의상 어딘가에 자기 원소 색을 **반드시** 포인트로 넣는다 |
| 채도 | **탁한 파스텔.** 저작된 초상의 실측 채도가 낮다(§2-3b). 순색 금지 |
| 주색 출처 | 그 유닛의 **초상에서 뽑는다.** `.tres` 의 `tint` 는 디버그 색이라 쓰지 않는다 |
| 배경 | **완전 투명 PNG.** 접지 그림자는 화면이 따로 그린다 — 그림에 넣지 않는다 |
| 방향 | **오른쪽을 보는 측면 3/4.** 아군은 우측(적 쪽)을 본다. 적은 좌우 반전해서 쓰지 않고 **왼쪽을 보게** 그린다 |
| 자세 | 제자리 전투 대기. 무기를 들고 무게중심을 약간 낮춘다. 걷는 중간 자세 금지 |
| 여백 | 캔버스 좌우에 각 5%, 위에 5%. **발끝은 캔버스 밑변에 붙인다** (발 기준선이 밑변이다) |

### 2-3a. 화풍의 참고 대상은 **이 프로젝트의 초상**이다

타사 상업 아트를 스타일 목표로 삼지 않는다. 리그 오브 레전드 / TFT 키 아트 같은
Riot Games 아트를 "이런 느낌으로" 참고하자는 방향은 **폐기했다.** 저작권 문제이고,
그쪽은 7~8등신 실사풍 고채도 키 아트라 이 게임의 4등신 파스텔 초상과 화풍 자체가
다르다 — 섞으면 초상과 전장이 다른 게임처럼 보인다.

정본은 두 개뿐이다.

| 무엇 | 어디 |
|---|---|
| 화풍·색감·캐릭터 정체성 | `assets/sprites/characters/portraits/*.png` (이 저장소의 초상 6장) |
| 규격·규율 | 캐릭터 아트 에셋 제작 가이드 (사용자 제공) |

`art/character-assets/v1/manifest.source.json`(#477)이 이미 이 규약을 따른다 —
캐릭터별 `reference` 가 저장소 초상 경로이고, 머리 모양·의상·팔레트를 거기서 뽑아 적었다.
**새 프롬프트도 초상을 첨부하고 "같은 인물"이라고 말하는 방식을 쓴다.**

### 2-3b. 색감 — `tint` 를 쓰지 말고 **초상에서 뽑는다**

저작된 초상의 팔레트를 실측했더니 **전부 탁한 파스텔**이었다. 채도가 낮고 명도가 높고,
피부·하이라이트가 근백색(`#F8F0F0` 계열)으로 화면의 10~20% 를 차지한다.

그런데 `.tres` 의 `tint` 는 `#FF4C4C` · `#0080FF` · `#4CFF4C` 같은 **순색**이다.
그건 네모를 칠하려고 급히 정한 디버그 색이고 **원본 일러스트의 색감이 아니다.**
`tint` 를 주색으로 삼아 스프라이트를 뽑으면 초상과 나란히 놓았을 때 다른 게임처럼 보인다.

**규칙: 주색은 그 유닛의 초상에서 뽑는다.** 아래는 실측값이다
(근백색 = 피부·하이라이트는 주색 후보에서 제외했다).

| 유닛 | 초상 | 주색 1 | 주색 2 | 보조 | 실측 채도 |
|---|---|---|---|---|---|
| 하랑 | `harang.png` | `#90B898` | `#A8C0D8` | `#787860` | 낮음 |
| 미나 | `mina.png` | `#B08060` | `#C8A890` | `#582820` | 낮음 |
| 설아 | `seola.png` | `#C8D8E8` | `#B0B8D0` | `#8088A0` | **거의 무채색** |
| 태희 | `taehee.png` | `#202028` | `#808088` | `#686870` | **거의 무채색** |
| 아린 | `arin.png` | `#C08078` | `#E8D0B8` | `#A86860` | 낮음 |
| 강지 | `gangji.png` | `#B88870` | `#D0A890` | `#402820` | 낮음 |
| 서아 (적) | `seoa.png` | `#C8A088` | `#987060` | `#604038` | 낮음 |
| 벨로 1 (적) | `girl_violet.png` | `#383030` | `#B0A8C8` | `#384870` | 낮음 |
| 벨로 2 (적) | `velociraptor_beastfolk_2.png` | `#303030` | `#384070` | `#D0C0D8` | 낮음 |

> 벨로 2 의 초상은 `girl_lilac.png` 와 팔레트가 완전히 같다 — **같은 그림이다.**
> 두 벨로를 색으로만 구분할 수 없으니 실루엣(자세·꼬리 길이·장식)으로 갈라야 한다.

초상이 없는 셋(매머드 수인 · 매머드 우두머리 · 여왕)은 뽑을 원본이 없다.
`tint` 를 **탁하게 눌러서** 쓴다 — 채도를 절반 이하로, 명도를 올린다.

| 유닛 | `tint` (원본) | 눌러 쓸 주색 |
|---|---|---|
| 매머드 수인 | `#8C664C` | `#A08876` / `#6E5A4C` |
| 매머드 우두머리 | `#FFFFFF` | `#C8BCB0` / `#8A8078` (장식만 대비를 준다) |
| 여왕 | `#8B6BB0` | `#9C8CB8` / `#5F5478` |

**원소색만은 예외다.** `#FF6B35` 같은 순색을 그대로 쓴다 — 속성 표시가 탁해지면
그것이 곧 정보 손실이다. 다만 **한 곳에만** 넣는다(§2-3).

### 2-4. 표시 칸은 #492 에서 1.5배로 키웠다

원래 아군 칸이 84px 이었다. 가이드 §2.3 이 1080p 에서 340~400px(720p 환산 227~267px)를
요구하는데 **3배 차이**라, 화면에서 캐릭터가 너무 멀리 있는 것처럼 보였다.

#492 가 **1.5배**로 키웠다(84×126 / 93×117). 함께 움직인 값들:

| 값 | 전 | 후 |
|---|---|---|
| 아군 칸 | 56×84 | **84×126** |
| 적 칸 | 62×78 | **93×117** |
| 적 간격 `ENEMY_SLOT_STEP` | 112 | 124 |
| 아군 간격 `ALLY_SLOT_STEP` | -84 | -106 |
| 적 클러스터 폭 `CLUSTER_W` | 100 | 118 |
| 조준 프레임 `AIM_FRAME` | 58×54 | 88×106 |
| 하단 초상 `PORTRAIT` | 42×36 | 60×52 |
| 타임라인 칩 | 60×32 | 80×44 |
| 액션 버튼 | 92×66 | 118×84 |

**아트는 다시 뽑지 않았다.** 제작 캔버스가 4배(224×336)라 1.5배 확대해도 원본 해상도
안이다. 4배로 그려 둔 값어치가 여기서 나왔다.

여전히 가이드의 227~267px 에는 못 미친다. 더 키우려면 적 5체가 1280 폭에 들어가는지
다시 계산해야 한다 — 지금도 맨 오른쪽 적의 클러스터가 화면 끝에서 39px 밖에 안 남는다.

## 3. 대상 목록 — 12체

원소색은 `TurnCombat.ELEMENT_COLOR` 값이다. `tint` 는 지금 네모를 칠하는 색이고
**디버그용 원색**이라 그대로 쓰지 말 것 — 주색을 정할 때 참고만 한다.

**여섯 명 전원 초상이 있다.** 프롬프트에 초상을 첨부하고 "같은 인물"이라고 말하면
디자인을 다시 발명할 필요가 없다 — 머리 색·머리 모양·의상 실루엣·장식을 그대로 옮긴다.

> 무기 힌트는 **클래스·물리 타입에서 끌어낸 제안**이다. 저작된 무기 디자인이 있으면
> 그쪽이 정본이다. 물리 타입은 전투 규칙(자물쇠 해제 조건)이므로 무기 모양이 그것과
> 어긋나면 플레이어가 헷갈린다 — 참격은 날붙이, 관통은 찌르기/사격, 강타는 둔기.

### 적 6

적은 전원 원소가 **충격**이라 원소색 포인트가 겹친다. 대신 **약점 속성**을 몸 어딘가에
드러내면 전장에서 분절 바와 짝지어 읽힌다(선택).

**적도 전원 여성 인간형(수인 소녀)으로 그린다.**

저작된 초상 셋이 이미 그렇다 — 서아는 뿔과 꼬리가 달린 소녀이고, 벨로시랩터 둘도
소녀 초상이다. 그런데 짐승 셋(매머드 · 우두머리 · 여왕)만 초상이 없어서 짐승으로
남아 있었고, 그 결과 **같은 전장에 소녀와 짐승이 섞여 톤이 갈렸다.** 셋 다 같은
문법으로 맞춘다: **소녀 체형 + 종의 특징(상아·꼬리·날개·귀)** 이다.

| 이름 | id | 약점 | 초상 | 여성 인간형 디자인 |
|---|---|---|---|---|
| 벨로시랩터 수인 | `velociraptor_beastfolk` | 한기 · 충격 | 있음 (`girl_violet`) | 초상 그대로. 낮은 자세, **긴 꼬리 + 갈고리 손톱**, 민첩한 실루엣 |

> **초상이 있는 셋은 초상을 첨부하고 그리게 한다.** 같은 인물이 전장과 초상에서 다르게
> 생기면 그게 제일 먼저 눈에 걸린다. 서아가 지금 정확히 그 상태다.
>
> 초상이 없는 셋은 이 스프라이트가 **그 캐릭터의 첫 디자인**이 된다. 나중에 초상을
> 그릴 때 여기에 맞추게 되므로, 뽑은 결과를 이 표에 되먹여 적어 둘 것.

### 이름은 그대로 둔다

`display_name` 은 "매머드 수인" · "여왕" 그대로다. **디자인만 바꾸고 데이터의 이름·
약점·스텟은 건드리지 않는다** — 이름을 바꾸면 저작된 스테이지·스토리·튜토리얼의
대사와 어긋난다. 이름 변경이 필요하면 별도 이슈다.

### 4-1. 색감이 초상보다 진하고 어둡다

초상과 전투 스프라이트의 평균 채도·명도를 실측했다.

| 유닛 | 초상 채도 | 전투 채도 | 차이 | 초상 명도 | 전투 명도 |
|---|---|---|---|---|---|
| 설아 | 0.100 | 0.192 | **+92%** | 217 | 196 |
| 벨로 1 | 0.108 | 0.163 | +51% | 165 | 162 |
| 미나 | 0.241 | 0.327 | +36% | 199 | **158** |
| 아린 | 0.261 | 0.341 | +31% | 176 | 178 |
| 하랑 | 0.130 | 0.167 | +28% | 202 | **171** |
| 서아 | 0.233 | 0.279 | +20% | 186 | **119** |
| 강지 | 0.372 | 0.265 | −29% | 129 | 161 |
| 태희 | 0.090 | 0.080 | −11% | 133 | 165 |

8체 중 6체가 더 진하고, 대부분 더 어둡다. §2-3b 의 실측 주색을 프롬프트에 **hex 로
박아 넣어야** 한다 — "탁한 파스텔로" 같은 말로는 이 폭이 잡히지 않았다.

### 4-2. 세 명이 단색으로 물들었다 — 피부까지

하랑·설아·태희가 **전신 한 색**이다(민트 / 하늘 / 회색). 피부까지 그 색이라 초상의
"살색 피부 + 색 있는 의상" 구조가 사라졌다. 설아의 채도 +92% 가 이것 때문이다.

초상 구조는 이렇다.

| 유닛 | 초상 | 1차 산출물 |
|---|---|---|
| 하랑 | 살색 피부 + 흰 셔츠 + 데님 반바지 + 민트 머리 | **전신 민트** |
| 설아 | 살색 피부 + 흰·연청 의상 + 은청 머리 | **전신 하늘색** |
| 태희 | 살색 피부 + 검정 원피스 + 스카프 + 흰 머리 | **전신 회색**, 얼굴이 스카프에 묻혀 눈만 보인다 |
| 미나 | 금발 트윈테일 + 흰 셔츠 + 붉은 넥타이 + 갈색 치마 | 갈색·베이지, **셔츠·넥타이 없음** |
| 아린 | 금발 단발 + 크림 가디건 + 검정 반바지 | **잘 맞는다** |
| 강지 | 갈발 + 크림 가디건 + 갈색 치마 + 가방 | **잘 맞는다** |

다음 판 프롬프트에 넣을 문장:

```
■ 피부는 물들이지 마라
피부는 살색(#F0D8C8 계열)으로 유지한다. 머리색·의상색을 몸 전체에 곱하지 마라 —
첨부한 초상은 "살색 피부 + 색 있는 의상" 구조다. 전신을 한 색으로 물들이면
같은 인물로 보이지 않는다.

■ 의상을 새로 발명하지 마라
첨부한 초상의 상의·하의·신발·장식을 그대로 옮긴다. 무기만 추가한다.
```

### 4-3. 적 3체가 아직 짐승이다

매머드 수인 · 매머드 우두머리 · 여왕이 네발 짐승과 익룡으로 나왔다. 서아와 벨로
둘은 소녀라서 **같은 전장에 소녀와 짐승이 섞여 톤이 갈렸다.**

§3 "적 6" 표의 여성 인간형 디자인 열이 이걸 위해 있다. 특히 여왕은 **부리를 얼굴로
만들지 말고 투구·머리 장식으로** 두어야 한다 — 1차 산출물은 완전한 용 머리였다.

### 4-4. 곁들여 나온 문제: 접지 그림자

네모였을 때는 눈에 띄지 않던 것이 그림을 넣고 드러났다. 전투 화면이 그리는 접지
그림자가 `ColorRect` 60×12 (`Color(0,0,0,0.32)`, `position (-30,-6)`)라, 발밑에
**딱딱한 검은 판**으로 보인다. 아트 이슈가 아니라 화면 쪽 다듬을 거리다.
