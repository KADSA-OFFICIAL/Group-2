# 기존 일러스트 기반 캐릭터 아트 에셋 · 1차 패키지

대상: 강지, 아린, 하랑, 미나, 태희, 설아.

기준은 KADSA-OFFICIAL/Group-2의 기존 일러스트다. 머리색·헤어·눈·의상·장식·꼬리 등 식별 요소를 기준으로 비도트 초상, 컷인, 전신을 제작했다. 앞서 폐기한 새 디자인은 이 패키지에 포함하지 않았다.

**이 패키지는 가이드 전체를 완료한 전투 리그 납품물이 아니다.** AI로 만든 이미지의 형태와 투명 배경을 확인한 1차 아트 에셋이다. 리그 부품, 표정 슬롯, 스켈레톤, 애니메이션은 미포함이다.

## 파일 구성

각 캐릭터 폴더의 `char_{ID}_...` 파일:

| 파일 | 규격 | 사용처 |
|---|---|---|
| portrait_square.png | 256 × 256, RGBA | 초상 원본 |
| portrait_hud.png | 42 × 36, RGBA | 작은 HUD 초상 |
| portrait_wide.png | 60 × 32, RGBA | 눈·얼굴 중심 별도 크롭, 타임라인 칩 |
| silhouette.png | 256 × 256, 검은 실루엣/알파 | 식별성 검토 |
| cutin.png | 2400 × 1350, RGBA | 좌측 40%가 완전히 비어 있는 컷인 |
| cutin_overscan.png | 2800 × 1350, RGBA | 기본 뷰포트 좌우 200px 작업 여유 포함 |
| fullbody.png | 1400 × 2200, RGBA | 편성용 전신, 외곽 여백 최소 10% |
| emblem.svg | viewBox 0 0 128 128, 단색 | 기존 외형의 모티프를 바탕으로 새로 만든 엠블럼 시안 |

`portrait-atlas.png`는 초상만 담은 1024 × 1024 아틀라스이며 위치는 `portrait-atlas.json`에 기록했다. 전투 아틀라스가 아니다.

`portrait-review.png`에서 42 × 36 / 60 × 32 실제 픽셀 크기와 실루엣을 확인할 수 있다. `lineup-preview.png`는 전체 에셋을 함께 보는 축소 시트다.

기본 PNG 42개 전부에서 지정 크기와 실제 알파를 확인했다. 컷인 6개의 왼쪽 40%가 완전히 투명하며, 전신 6개의 최소 10% 여백 검사를 통과했다. `verification.json`에 파일별 결과가 있다. 이 검사는 아래 작화 예외나 리그 검증을 대신하지 않는다.

## 적용한 기준

- 작은 초상을 먼저 제작하고 얼굴을 가리던 손과 과도한 상반신을 제거했다.
- 초상별로 정사각형·HUD·가로형 파일을 별도로 내보냈으며 가로세로를 늘려 얼굴을 찌그러뜨리지 않았다.
- 정사각 초상과 전신은 알파 경계 기준으로 여백을 맞췄다.
- 컷인 왼쪽 960px에는 캐릭터, 효과, 글자를 넣지 않았다. 이름·스킬명은 게임에서 합성한다.
- 배경, 속성 광원, 속도선, 입자 효과는 그림에 넣지 않았다.
- 작업 배경색을 제거하고 실제 알파 채널이 있는 PNG로 내보냈다. 검은색 화면 배경은 파일에 구워진 배경이 아니다.
- 원본과 생성 이미지의 해상도는 서로 다르다. 지정 규격으로 리샘플링한 납품 캔버스이며, 모든 이미지가 해당 픽셀 수로 직접 생성된 것은 아니다.

## 검수 예외와 남은 작업

1. **외형 보존을 우선했다.** 강지·아린은 단발 실루엣이 비슷하고, 밝은 머리색의 캐릭터도 여러 명이다. 모든 조합에서 Hue 40°/명도 30% 차이가 난다고 인증하지 않는다. 42px에서는 머리색·뿔·묶음·귀·목도리 형태를 함께 사용해 식별해야 한다.
2. 원본 의상색을 유지했다. 가이드의 7원소와 이 6명의 대응은 확정 정보가 없으므로 임의의 속성을 배정하거나 옷을 재색칠하지 않았다. 엠블럼도 속성 확정을 의미하지 않는다.
3. 팔레트는 원본의 주요 색군을 유지했다. 피부·눈·음영·금속을 포함한 엄격한 4색 제한 및 모든 선의 정확한 4px/2px 두께는 미검증이다.
4. 전신의 비율은 원본의 인상을 유지해 재작화했다. 모든 캐릭터가 정확히 동일한 7~7.5등신이라고 계측 인증하지 않는다.
5. 200px 오버스캔은 작업 캔버스 여유다. 실제 슬라이드 거리와 상하 크롭은 게임 연출에서 검수해야 한다.

   설아 컷인은 다른 5명의 허벅지까지 보이는 구도와 달리 얼굴·어깨 클로즈업이다.
6. **리그 부품 24~30개, 눈 4종·입 4종 슬롯, 좌우 손 3종, 접지 그림자, 10종 애니메이션과 타격 이벤트는 아직 제작하지 않았다.** 전신 PNG를 잘라 놓는 것만으로 가려진 관절이 복원되지 않으므로 이를 리그라고 부르지 않는다. 가이드 §7의 권고대로 확정 원화를 바탕으로 가려진 부분까지 부품별 재작화하고 리깅 검수해야 한다.
7. 전투 리그가 없으므로 2048 × 2048 전투 아틀라스, premultiplied-alpha 런타임 설정, ASTC/ETC2 패키징도 미포함이다. 제공 PNG는 일반 straight-alpha다.
8. 손·의상 장식·얼굴 일관성은 생성 이미지 특성상 최종 수작업 검수가 필요하다. 미나는 셔츠가 가슴을 완전히 덮는 형태로 제작 지시했다.
