# 강지·아린 화풍 통일 — #485

기존 하랑·미나·설아 초상의 얇고 부드러운 선, 평면 파스텔 색감으로 강지·아린을 다시 제작했다.
머리 모양·핀·잎 장식·눈 색·카디건·가방 등 인물의 외형을 유지했다.

`source-plates/`는 인물별 전신·얼굴 아이콘·컷인을 개별 이미지 생성한 제작 원본이다.
생성 프롬프트는 `../../battle-sprites/prompts.json`에 함께 보관한다.
재출력: `godot --headless --path . --script tools/prepare_character_restyle.gd`.

| 용도 | 크기 |
|---|---|
| 전신 | 1400×2200, 최소 10% 여백 |
| 얼굴 아이콘 | 256×256 |
| HUD / 가로 아이콘 | 42×36 / 60×32 |
| 검수용 실루엣 | 256×256 |
| 컷인 | 2400×1350, 왼쪽 40% 완전 투명 |
| 컷인 오버스캔 | 2800×1350 |

게임의 `assets/sprites/characters/portraits/{arin,gangji}.png`도 교체했다.
공유 초상은 941×1691, 인물 높이 92%로 정규화했으며 얼굴 좌표는 `data/portraits/portrait_meta.tres`에 있다.
편성·대화·전투 HUD·기존 오의 컷인 경로는 이 공유 초상의 새 그림체를 사용한다.
전용 와이드 컷인은 납품 에셋이며, 현재 런타임의 초상 선택 동작을 바꾸지 않는다.

PNG는 straight alpha다. 피부·눈·의상 색을 4색으로 강제 매핑하지 않는다.
리그 부품·표정 슬롯·애니메이션은 정지 일러스트가 아니므로 이 패키지에 포함하지 않는다.
