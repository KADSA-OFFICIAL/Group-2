# 새 오의 24프레임 세트

생성 순서: 강지 → 설아 → 미나 → 태희 → 하랑. 각 00.png~23.png, 총 120장, 모두 1024×1536 PNG입니다. 이미 만든 아린 세트는 재생성하지 않았고 이 묶음에서 제외했습니다.

Codex 내장 ImageGen으로 개별 프레임을 생성했습니다. 캐릭터별로 기준 프레임 00·04·08·11·16·23을 먼저 생성하고 원문 지정 순서대로 중간 프레임을 생성했습니다. prompts 폴더에는 원문, remaining_generation_prompts.json에는 프레임별 원문과 참고 이미지 관계가 있습니다. 실제 호출에는 아래 보충조건을 적용했습니다.

- 공통: 참고 이미지의 얼굴·색·장비 유지, 정면/왼쪽 3/4 시점, 전신과 무기 여백, 같은 머리 크기·발바닥 기준선, 중간 동작을 끝점 복제 대신 별도 자세로 표현하도록 요청했습니다.
- 강지: 인간 캐릭터로 꼬리·뿔·날개를 추가하지 않도록 지정. 지팡이와 구슬 전체를 화면 안에 포함하도록 요청했습니다.
- 설아: 08 프레임의 원래 의상이 도구 안전 검사에서 차단되어, 불투명한 하이넥 파란 전투 튜닉과 반바지로 변경했습니다. 앞서 생성된 00·04도 같은 의상으로 수정했습니다. 머리·지느러미 귀·꼬리·창은 유지했습니다.
- 미나: 흰 셔츠가 가슴 전체를 덮도록 지정했습니다. 붉은 넥타이·주름치마·날개·꼬리·레그워머·봉은 유지했습니다. 원문은 둥근 방패라 서술하지만 무기 참고 그림은 길쭉한 방패여서 결과는 참고 그림의 형태를 따릅니다.
- 태희: 검 두 자루, 이빨 목도리, 회색 장갑·꼬리, 흰 트윈테일과 맨발을 유지하도록 지정했습니다.
- 하랑: 녹색 의상·꼬리의 원래 색을 유지하고 대검의 머리 위 여백을 요청했습니다. 원문은 마젠타 배경이며 결과도 마젠타입니다. 보충 문장에 녹색 배경이 혼재했으나 원문과 참고 프레임의 마젠타가 반영됐습니다.

## 검수 결과와 사용 범위

각 캐릭터 24장, 파일 번호 누락 없음, 모든 해상도 1024×1536, SHA256 기준 동일 파일 중복 없음을 확인했습니다. remaining_validation.csv에 파일별 해상도·좌상단 배경 RGB·해시를 기록했습니다.

생성 결과를 눈으로 확인했으며, 일부 중간 프레임은 앞뒤 기준 자세와 매우 비슷하고 움직임 간격이 일정하지 않습니다. 파일 해시가 서로 달라도 자세 차이가 충분하다는 뜻은 아닙니다. 머리 크기·발 위치·무기 길이와 의상 세부가 프레임마다 조금씩 변하며 일부 무기 끝·효과가 가장자리 가까이 있습니다. 배경도 정확한 단일 RGB로 보정하지 않았습니다.

따라서 이것은 생성된 원본 프레임 묶음입니다. 부드러운 게임 애니메이션 완성본이나 투명 배경/픽셀 정렬 완료본으로 검증하지 않았습니다. 엔진 적용 전 크로마키 제거, 피벗·크기 정렬 및 중간 동작 보정이 필요합니다.
