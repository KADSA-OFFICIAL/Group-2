아스트라 오의 — 로컬 2D 리미티드 애니메이션

제작 결과
- 캐릭터별 MP4 6개: 1080×1920, 24fps, 72프레임, 3초, H.264, 무음.
- 마지막 15프레임(0.625초)은 동일한 마무리 자세를 유지합니다.
- 설아/미나/태희/아린은 초록색, 하랑/강지는 자홍색 배경입니다.
- *_transparent_frames.zip: 같은 동작의 RGBA PNG 72장(1080×1920). 000.png~071.png 순서로 24fps로 가져오세요.
- preview_all.mp4: 6명 동시 재생 미리보기. index.html: 개별 재생/다운로드 화면.
- keyframes/: 이미지 생성으로 제작한 6포즈 시트 및 정렬된 포즈.
- source/: 로컬 렌더링 및 검증 스크립트, 원본 프롬프트.

제작 방식과 범위
내장 이미지 생성 도구로 캐릭터마다 6개의 공격 포즈를 그린 뒤, 로컬 코드로 포즈 전환·몸 기울기·외곽 머리카락 움직임을 합성했습니다. Runway를 사용하지 않았습니다. 얼굴과 무기가 겹치는 자동 보간은 최종 영상에 사용하지 않았습니다. 영상은 24fps 컨테이너지만 독립적으로 그린 원화는 캐릭터별 6장인 리미티드 애니메이션입니다. 1080×1920 출력은 원화 포즈를 확대하여 렌더링한 것이므로 원화 자체가 해당 해상도의 풀 프레임은 아닙니다.

참조 초상과 무기 이미지를 함께 사용했으나 생성 과정에서 복장·비율·무기·표정의 세부 차이가 생겼습니다. 원문의 매 프레임 동일성이나 모든 동작 지시를 완전히 재현한 결과는 아닙니다. MP4의 색상은 영상 압축으로 순수 #00FF00/#FF00FF에서 아주 조금 달라질 수 있습니다. 정밀 합성에는 투명 PNG 시퀀스를 사용하세요.

동작
설아: 얼음 창 준비 → 뒤로 당기기 → 왼쪽 아래 찌르기 → 마무리.
미나: 방패 준비 → 몸 낮추기 → 왼쪽 방패 돌진 → 방패/봉 마무리.
태희: 쌍검 준비 → 낮은 자세 → 교차 베기 → 낮은 마무리.
하랑: 대검 들어 올리기 → 내려치기 → 낮게 든 대검 마무리.
아린: 석궁 들기 → 왼쪽 조준 → 발사/반동 → 조준 유지.
강지: 지팡이 기도 준비 → 머리 위로 올리기 → 구체 발광/마무리.

재생성
Python + numpy + Pillow + opencv-python-headless + imageio-ffmpeg 설치 후 source/render.py를 실행합니다. 출력 폴더의 keyframes/*_sheet.png가 필요합니다. source/package.py는 미리보기/검증/패키지를 만듭니다.
