Shared sheet instructions (last revision, used for Mina through Gangji):
Create a professional 2D hand-drawn ANIMATION KEYFRAME SPRITE SHEET for an attack animation, using the two supplied reference images. Reference 1 dictates exact character identity, face, hair colors, outfit and illustration style. Reference 2 dictates weapon design and how the character holds it. Exactly SIX sequential full-body poses of the SAME character, arranged on an exact uniform 3-column by 2-row grid, reading left-to-right, top-to-bottom. Canvas 1536x1536. Each of the 3 columns is 512 pixels wide, each of the 2 rows is 768 pixels high. Each cell is PORTRAIT. Every cell same size, same scale, same camera, same foot baseline. CRITICAL: generous empty transparent gutter of 80 pixels between every figure and between rows. All weapon tips and hair must remain inside that figure's cell. No overlaps between neighboring sprites. Draw about 7-head adult proportions as first reference, NEVER chibi. Each figure occupies ~65% of cell height and stays entirely within its own cell. Consistent face and outfit and weapon across all poses. No border, no labels, no text, no cast shadows, no floor, no scenery, no grid lines. TRUE TRANSPARENT BACKGROUND. Clean thin linework and cel shading, beautiful reference-matched 2D anime illustration. Use no motion blur, no duplicate limbs, no huge effects. Weapon is physically held in the hands, preserve anatomy. Six clear animation beats: 1 ready, 2 anticipation, 3 maximum windup, 4 attacking, 5 follow-through, 6 final hold. Character attacks toward SCREEN LOWER LEFT. This is production animation artwork with solid coherent shapes, not a storyboard.
